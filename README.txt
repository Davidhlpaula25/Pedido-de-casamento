PEDIDO DE CASAMENTO - KAROLLINY

Como testar:
1. Abra o arquivo index.html no navegador.
2. Para uma experiência melhor no celular, publique na Vercel.

Como publicar na Vercel:
1. Entre em https://vercel.com
2. Crie um novo projeto.
3. Envie esta pasta ou coloque os arquivos em um repositório GitHub e importe.
4. Não precisa configurar build: é um site estático.

Personalização rápida:
- Textos: edite index.html e o array "story" em script.js.
- Fotos: substitua os arquivos dentro da pasta assets mantendo os mesmos nomes.
- Nome: procure por "Karolliny Vieira Santos" no index.html.

Brincadeira:
- Na primeira pergunta, o botão SIM foge algumas vezes para impedir uma resposta imediata.
- Depois das fotos, a pergunta volta de verdade.
- Na pergunta final, o botão NÃO foge e o botão SIM funciona.
- Ao clicar em SIM, aparecem confetes e a mensagem "Agora olha pra mim...".
